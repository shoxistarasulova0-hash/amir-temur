AMIR TEMUR — 30 SONIYALIK VIDEO GENERATORI
==========================================

FAYLLAR
- main.py: asosiy dastur
- requirements.txt: Python kutubxonalari
- Dockerfile: Render serveri uchun FFmpeg va Python o'rnatadi
- render.yaml: Render sozlamalari

GITHUB VA RENDERGA YANGIDAN JOYLASH
1. ZIP faylni oching.
2. Ichidagi amir_temur_video_fixed papkasidagi barcha fayllarni GitHub repository'ning bosh qismiga yuklang.
   Eski main.py o'rniga yangisini almashtiring.
3. GitHub'da o'zgarishlarni Commit qiling.
4. Render > amir-temur-video > Manual Deploy > Deploy latest commit ni bosing.
5. Deploy tugagach /health sahifasida {"ok": true} chiqishini tekshiring.
6. Saytni ochib "Videoni yaratish" tugmasini bosing.

E'TIBOR
- Video yaratish uchun internetga chiqish kerak (Wikimedia rasmlari va onlayn ovoz).
- Agar internetdan rasm topilmasa, dastur zaxira kadr ishlatadi; bu xatoga olib kelmasligi kerak.
- Render Free rejasi uyquga ketishi yoki vaqt/resurs chekloviga duch kelishi mumkin.
- Hech bir kodni "umuman muammosiz" deb kafolatlab bo'lmaydi; ushbu nusxada ko'ringan zaif zaxira-kadr kodi mustahkamlandi va xatolarni aniqlash osonlashtirildi.
- API_TOKEN qiymatini ommaga yubormang.
